# Live Logger

> Archived as this project is considered finished. Available at: https://live-logger.3-foxes.com

Simple, friendly, for Michelle and Co.

- Type or paste a message and it appears immediately on the screen.
- You can edit or delete any message if you change your mind.
- Use up to three separate sessions (like browser tabs) to keep different runs apart.
- When you want to save a session, click Download to get a CSV file.
- Reset clears the current session so you can start fresh.
- Use multiple tabs for EVEN MORE sessions.

> NOTE: Not recommended on Edge due to SessionStorage bugs.

Enjoy! 🙂
